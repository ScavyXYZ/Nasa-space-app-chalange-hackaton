# Демореліз / Planetary Atlas — 15 листопада 2026

**Поточна маршрутизація v2:** [planetary_routing_v2.md](planetary_routing_v2.md).
Глобально — двобічний пошук із градієнтом, довжиною по схилу та якістю
MOLA-вимірювань; локально точний A*. Авто обирає HiRISE → CTX → MOLA
серед фактично завантажених DEM. Глобальний CTX тепер використовує
нативні рівні referenced Esri service, а не урізаний опис Trek WMTS.

Оновлення наближення: [imagery_zoom.md](imagery_zoom.md). Додано чотири
оптичні WMTS-джерела (разом 8), динамічний LOD глобуса, авто HD у 2D,
CTX/HiRISE Jezero та виправлення порядку підкладок. 53 Python-тести й
окремий реальний zoom E2E пройшли; високодетальні тайли потребують мережі.

## Функціональний обсяг

- Єдиний планетарний робочий простір: глобус / 2D-атлас, перехід до Jezero,
  автоматичне підключення зареєстрованої CTX-оптики при наближенні.
- MOLA **16 ppd**, 2880 × 5760, 0,0625°, ~3,7 км; висоти й counts.
  Попередній 4 ppd архів збережений, але runtime обирає архів із metadata.
- Глобальна геологія SIM 3292: **1 311 полігонів, 44 одиниці**.
  Для відображення спрощення 0,035°; point/route queries — вихідні геометрії.
- Чотири перевірені WMTS-джерела NASA Trek: MOLA/HRSC color hillshade,
  MOLA color hillshade, THEMIS daytime/nighttime IR. Це зображення,
  **не** numeric DEM або живі температури.
- 168 локально кешованих тайлів zoom 0–2; обмежена кількість зовнішніх
  завантажень, cache і локальна Viking-підкладка при збої джерела.
- До чотирьох впорядкованих зупинок, редагування/видалення/переміщення,
  альтернативні штрафи, збереження й відновлення параметрів.
- `/api/expedition`: автовибір CTX 20 м, якщо **всі** точки в Jezero;
  інакше MOLA. Різні DEM не зшиваються приховано.
- Орбітальний обліт із паузою, ручне переміщення профілем.
  Анімація запускається лише дією користувача; невидима вкладка її призупиняє.
- Звіт із координатною схемою, профілем, етапами, геологією й джерелами;
  HTML завантажується, PDF зберігається через діалог друку браузера.
- GeoJSON з параметрами/датумом, QR посилання на координатний план.
- Три локальні NASA-фотоісторії з кредитами та застереженням про координати.
- Швидка мобільна навігація, адаптивні панелі й reduced-motion.

## Перевірки

`python -m unittest discover -s tests -v`: **53 тести**.
`npm --prefix frontend run build`: успіх, лишається попередження про
розмір Three.js/Plotly chunks.

Новий acceptance:
`python tests/smoke_atlas_browser.py --url http://127.0.0.1:8003`.
Результати, скриншоти, реальний згенерований PDF:
`artifacts/release/`.

Попередні шість браузерних сценаріїв збережені. Фактичний актуальний
результат кожного дивіться у звітах, а не в історичних скриншотах.
У поточній перевірці всі шість попередніх сценаріїв пройшли повторно.
Новий сьомий acceptance-сценарій також **пройшов через справжній публічний
HTTPS tunnel**, включно з QR, завантаженням звіту, глобальним та CTX-пошуком.
Запис URL і результат: `artifacts/release/public_acceptance.json`.
В усіх сценаріях JS page errors: 0. Телефонні формати перевірені Chromium
на 375 px, landscape й tablet; це не заява про тест на фізичному телефоні.

`/api/ready` перевіряє глобальне ядро, геологію, каталоги й основні
display assets. `/api/health` збережений для сумісності локального CTX.
Для мобільного інтернету ввімкнено gzip.

## Публічний показ

Безкоштовний Cloudflare Quick Tunnel:
`python scripts/share_demo.py --port 8003`.
Скрипт перевіряє SHA-256 офіційного cloudflared 2026.11.0 перед запуском,
не встановлює службу й не змінює firewall.

Поточний URL/PID: `artifacts/release/public_demo.json` (локальний,
gitignored). QR: `artifacts/release/demo-qr.png`.
Це тимчасовий tunnel, **не постійний cloud deploy**. Комп’ютер, backend,
тунель і мережа повинні залишатися ввімкненими. Посилання зміниться при
перезапуску. SLA, розподіленого rate limiting, акаунтів і черги завдань немає.

## Наукові межі, які не приховуються

- Глобальні маршрути наближені, дрібні перешкоди не визначаються.
- MOLA-продукт містить офіційну інтерполяцію: у 16 ppd приблизно 94,55%
  клітинок мають спостереження. Інтерполяція явно позначена.
- Універсальні 1–20 м дані для всієї планети не з’явилися.
- Детальніша numeric MOLA 128 ppd (~463 м на екваторі) **не інтегрована**;
  WMTS-візуалізація 463 м — окремий display product.
- Наземного фізичного симулятора, поточних позицій марсоходів,
  автоматичної стереореконструкції та GPU routing немає.
- ×10, декоративні контури та орбітальний політ — тільки візуалізація.
- Зміщення прив’язки до клітинок не входять у довжину шляху.
- Геологія глобальна й дрібномасштабна; точний geometric intersection
  не робить геологічну межу фізично точною.
