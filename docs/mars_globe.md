# Уся планета Марс

## Глобальний огляд

Початковий режим React — **«Планета»**. Three.js рендерить весь Марс з
реальною офіційною глобальною мозаїкою Viking MDIM 2.1, обертанням/zoom,
координатами натискання, fullscreen і переходом до локальної карти Jezero.
Можна оглянути всі довготи й обидві півкулі. Зміна режиму не скидає
вже розрахований локальний маршрут.

## Джерело й чесне трактування кольору

- Провайдер: **USGS Astrogeology / NASA Ames**, Viking Orbiter.
- Каталог: https://astrogeology.usgs.gov/search/map/mars_viking_colorized_global_mosaic_232m
- Завантажено офіційний **1km browse JPEG**: 36 708 552 байти, 21 339 × 10 670.
- Оригінал: `data/raw/globe/mars_viking_mdim21_colorized_1km.jpg`.
- Геоприв’язка: офіційний `.jpg.aux.xml`, збережений поряд.
- SHA-256, URL і координатні параметри: `data/processed/globe/metadata.json`.
- Browser texture: `data/processed/globe/mars_viking_colorized.jpg`, 4096 × 2048.
- Повний первинний GeoTIFF на 12 ГБ **не завантажувався**.

USGS прямо називає цей продукт **artistically colorized**. Це реальна
орбітальна мозаїка, офіційно колоризована NASA Ames, **не фотографія у
натуральних кольорах**. Кольори не вигадані нашим застосунком.

Вихідний продукт має native 232 м/піксель, але це **не роздільність
нашої глобальної текстури**: взято 1-кілометровий browse та зменшено для WebGL.
Глобальний огляд не замінює детальні CTX/HiRISE-зображення.

## Геометрія й обмеження

Текстура equirectangular, longitude −180…180°, latitude −90…90°,
планетоцентрична широта, східні довготи. UV-система SphereGeometry
узгоджена з цим діапазоном; позначка Jezero має координати 18.4447°N / 77.4508°E.

Це **сферична візуальна оболонка без глобального DEM displacement**.
Відносний розмір маркера перебільшено, щоб його можна було побачити.
Підсвічування — модель освітлення для читабельності, не симуляція поточного сонячного часу.

Глобальні натискання лише читають координати, а не створюють нереальні
маршрути без DEM. Аналіз висот/ухилів та A* залишаються всередині
перевіреної ділянки Jezero, з окремим HiRISE-фрагментом.

## Відтворення і перевірки

```powershell
python scripts/prepare_mars_globe.py
npm --prefix frontend run build
python -m unittest discover -s tests -v
python tests/smoke_globe_browser.py
```

Початковий urllib-запит до USGS повертав 403; стандартний `requests` до того ж
офіційного ресурсу отримав файл. Обхід авторизації чи вимкнення TLS не застосовувались.
Для JPEG відомого розміру використано кінцевий ліміт 240 млн пікселів і draft decode,
а не необмежене вимкнення захисту PIL.

Фактично перевірено WebGL, texture loading, поворот до іншої півкулі,
координати, fullscreen, mobile та перехід до справжнього A*.
Скріншоти: `artifacts/mvp/mars-whole-planet.png`, `mars-globe-mobile.png`.
Звіт: `artifacts/mvp/globe_e2e_report.json`.
